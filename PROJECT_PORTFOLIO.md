### FinFair — Plan with Clarity
**Student Financial Planning and University Affordability Simulator**

FinFair is a student-focused financial planning website designed to help prospective university students understand the financial challenges of higher education. It allows users to calculate monthly budgets, compare university expenses, convert costs between USD and BDT, and estimate four-year education costs.

Starting with an AI-assisted prototype, I used FinFair as an opportunity to develop my programming skills and understand how real websites function.

My hands-on contributions include adding a projected annual balance feature, connecting JavaScript calculations to HTML, running 21 automated tests through GitHub Codespaces, and publishing improvements to the live website.

Through this project, I have gained practical experience with HTML, CSS, JavaScript, GitHub, and software testing. I am continuing to improve FinFair while developing the skills to implement features more independently.
